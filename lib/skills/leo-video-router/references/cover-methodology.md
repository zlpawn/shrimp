# 视频多端通用封面工程手册 (Universal Video Cover Playbook)

## 一、核心哲学：双簧互补模型 (The Double-Act Model)

在注意力分发网络中，**封面图不是视频的“缩略图附件”，而是决定 80% 点击意愿的“第一视觉入口”**。

封面与标题必须协同配合，打出**“视觉冲击 + 事实锚定”的互补双簧组合拳**：

$$\text{封面（负责：制造视觉冲击 + 抛出反常悬念 + 极简大字）} \times \text{标题（负责：交代事实背景 + 圈定人群 + 搜索卡位）}$$

> [!CAUTION]
> **绝对禁忌：信息重合冗余！**
> 严禁将系统标题原封不动地整句复制粘贴到封面上。字小、繁杂、无悬念是击杀点击率的第一元凶。封面文字必须是标题的**极度脱水版（严格限定 4~10 个字）**。

## 二、通用高潮帧抽检四范式（与题材中立无关）

无论面对何种题材（科技、职场、生活 Vlog、美食、旅行、商业、知识科普、微短剧等），封面帧的选择必须遵循以下四大通用神经唤醒范式之一：

| 范式分类 | 核心唤醒机制 | 适用所有题材的特征描述 | 跨题材通用案例 |
| :--- | :--- | :--- | :--- |
| **1. 情绪峰值帧<br>(Peak Emotion)** | 梭状回面孔识别效应。<br>人类对真实面孔、微表情、眼神张力具有天然警觉。 | 视频中**惊讶、狂喜、崩溃、凝重、深思**的面部定格或对峙瞬间。画面必须真实，严禁僵硬死板。 | • 职场/个人故事：收拾工位的背影或长舒一口气的神情<br>• 美食/探店：入口瞬间的惊喜或不可思议表情<br>• 科技实测：看到报错崩溃或跑通瞬间的狂喜 |
| **2. 动作/张力峰值帧<br>(Peak Action & Tension)** | 运动感知补偿。<br>大脑潜意识渴望预测下一步动作，制造未完成感。 | 肢体正在操作、工具与材料接触、破坏或创造的**动作转折点**。 | • 手工/硬件：螺丝刀刚撬开外壳、焊锡冒烟瞬间<br>• 烹饪/美食：热油淋下、切开爆浆的刹那<br>• 运动/户外：悬空跨越、登顶回望的动态姿态 |
| **3. 奇观/反差峰值帧<br>(Contrast Spectacle)** | 认知失谐（Cognitive Dissonance）。<br>打破视觉预期与物理常识。 | 左右/上下分屏（Before vs After）、极端尺寸悬殊、破败与华丽的并置。 | • 测评/改造：改造成果对比、巨型设备 vs 掌心微型卡片<br>• 旅行/建筑：人像极小 vs 巍峨冰川/老建筑的壮丽悬殊<br>• 理财/生活：账单赤字 vs 最终结余反差 |
| **4. 局部聚焦/窥视缺口<br>(Mystery Focus)** | 好奇心剥夺感（Privation）。<br>人类对“看不清、藏着掖着”产生探究冲动。 | 关键细节特写、红圈关键线索标注、核心部件虚化或半遮挡。 | • 行业内幕/知识：关键文件的一行脱敏标注、核心参数特写<br>• 悬疑短剧：门缝中露出的眼睛、桌上遗留的神秘纸条<br>• 工具分享：系统核心监控面板的一个异常峰值红线 |

## 三、封面大字脱水与双簧实战矩阵（通用题材对照）

封面上的文字被称为“大字报”（Cover Hook），字阶必须至少占据画面高度的 1/6 ~ 1/4，保证在手机端 0.2 秒内扫视秒懂：

| 创作题材 | 封面大字（极简脱水 4~10 字） | 系统标题（事实 + 人群 + 搜索） | 协同双簧效果 |
| :--- | :--- | :--- | :--- |
| **技术 / 编程 / AI** | `“内存只要 30MB？！”` | 开源无头浏览器实测：这套架构彻底把内存打下来了 | 封面制造极致反常识，标题交代具体工具与搜索词 |
| **职场 / 成长 / 故事** | `“干了5年，我跑路了…”` | 为什么我不建议普通人学程序员？30岁裸辞后的真实困境 | 封面唤醒情绪痛点，标题锁定人群标签与长尾搜索 |
| **探店 / 美食 / 旅游** | `“人均20，吃到撑！”` | 在成都开了30年的地道老店：本地人才知道的隐藏吃法 | 封面抛出金钱利益诱惑，标题提供地理坐标与攻略背书 |
| **商业 / 财经 / 认知** | `“90% 的人都做反了”` | 别再死存定期了！普通家庭抗通胀的 3 个底层资产配置 | 封面指出常见认知错误，标题提供明确行动解决方案 |
| **好物 / 开箱 / 评测** | `“千万别买！大坑😭”` | 避坑指南：今年这 3 款数码产品谁买谁后悔，实测拆解 | 封面利用损失厌恶强力抓停，标题给出客观测评承诺 |

## 四、多端标准尺寸与排版安全区 (Platform Specifications)

不同平台的视频播放器有着截然不同的 UI 遮挡层，封面文字排版必须避开敏感盲区：

```
┌───────────────────────────────────────────────┐
│              顶部导航/返回按钮遮挡区          │ ◄── 顶部 12% 严禁放文字
├───────────────────────────────────────────────┤
│                                               │
│                                               │
│             【核心视觉与大字安全区】          │ ◄── 居中 75% 区域：
│           (主体视觉 + 4~10个粗体大字)          │     视线正中，保证各端裁切均不丢失
│                                               │
│                                               │
├───────────────────────────────────────────────┤
│    进度条 / 时长标签 (03:45) / 播放控制条遮挡区 │ ◄── 底部 15%（尤其是右下角）严禁放字
└───────────────────────────────────────────────┘
```

1. **哔哩哔哩 (Bilibili)**：
   - **比例与分辨率**：`16:9` 横屏，标准 `1920 × 1080`（最小不低于 `1140 × 640`）；
   - **避障盲区**：**右下角**固定展示视频时长（如 `12:34`），右下角 20% 区域严禁放置任何文字或关键主体；
2. **抖音 (Douyin)**：
   - **比例与分辨率**：`9:16` 竖屏，标准 `1080 × 1920`；
   - **主页陈列区**：抖音个人主页陈列封面是 `3:4` 居中裁剪，因此横向与纵向文字必须严格收拢在**正中央 3:4 视野内**；
3. **小红书视频 (RedNote)**：
   - **比例与分辨率**：`3:4` 竖版，标准 `1080 × 1440`；
   - **双列流避障**：顶部保留 120px、底部保留 160px。

## 五、动态可扩展工作流接口 (Open Workflow Contract)

在 `leo-video-router` 执行交付（Step 7）时，按以下开放接口交付封面：

1. **帧抓取时间戳标注**：
   - 在成片中定位出最佳情绪/动作帧的准确时间码（如 `01:23.45`）；
2. **双簧文案配对**：
   - 与生成的【3-Pick 战术标题】协同，输出匹配的封面大字建议（$\le 10$ 字）；
3. **多端归档落盘**：
   - 标准生成至 `<工程目录>/成片/发布版/封面.png`（默认 16:9），如需多端则派生 `封面_竖版_9_16.png`。
