# 后期效果

下游出完原始成片后，Router 可以再加的后期效果。都在本地用 ffmpeg 完成，不花生成费用；都要带 libass 的 ffmpeg，要求同 [subtitle-standard.md](subtitle-standard.md)。

**顺序**：先做后期效果，最后压字幕，这样字幕在最上层。

**新增效果**：一个效果一个脚本，放在 `scripts/`，再在这里加一节：什么时候用、命令、怎么检查。

## 片尾金句卡 `endcard.py`

**什么时候用**：结尾几秒画面停滞、没有台词，或者需要一句话点题。

**效果**：从金句出现起缓慢推镜 6% 并压暗；末帧定格延长；文字分两段，逐字淡入，第二段出现时字距慢慢拉开。

**文案**：先给用户 2–3 个候选，由用户选。隐喻比说教好，比如“路窄处，见人宽”比“做人要懂得礼让”耐看。两段式最好，第二段是落点。

```bash
python3 <本 skill 目录>/scripts/endcard.py "<工程目录>/成片/原始版/<原片>.mp4" "路窄处，" "见人宽" \
  "<工程目录>/成片/原始版/<原片>_final.mp4" --start 13.3
```

| 参数 | 默认 | 说明 |
|---|---|---|
| 第二段文字 | 无 | 可以省略，只写一段 |
| `--start` | 片尾前 2 秒 | 必须晚于最后一句台词结束，用转写结果或听感确认 |
| `--hold` | 0.8 | 末帧定格延长的秒数，成片会变长这么多 |
| `--y` | 0.76 | 文字底边的位置（占画面高度的比例）；挡脸就调小 |
| `--font` | 按系统选 | 同字幕字体 |

做完金句卡再对 `_final.mp4` 压字幕。最后抽一帧，确认文字没挡脸、在字幕上方（见 [production-playbook.md](production-playbook.md) 第 6 条）。
