# 兜底：未命中场景时

Router 不点名、不写死任何兜底 skill 的命令行，只负责把需求整理成通用视频提示词，再交给环境里已有的视频生成 skill。

## 何时兜底

- 用户描述需求后，按 [routing-matrix.md](routing-matrix.md) 仍然一个场景都不命中；
- 或用户拒绝安装推荐项目，回复「直接出片」。

用户已经拒绝安装时，兜底过程中不要再次推荐安装同一个项目。

## 通用视频提示词规范

按下面 7 个槽位整理需求。用户没说的槽位，根据上下文补一个合理值，并在交付时说明是补的。

| 槽位 | 写法要求 | 示例 |
|---|---|---|
| 主体 | 谁或什么，外观要具体到可画出来 | 一位穿黄色雨衣的小女孩 |
| 场景 | 地点、时间、天气、光线 | 雨后傍晚的老城区石板路，路灯刚亮 |
| 动作 | 主体在做什么，一个镜头只写一个主要动作 | 她踩进水坑，水花溅起 |
| 运镜 | 镜头怎么动、景别怎么变 | 镜头缓慢推近到积水倒影特写 |
| 风格 | 画面质感、色调、参考类型 | 电影感写实，暖橙与青蓝对比色调 |
| 时长与画幅 | 总时长和宽高比 | 8 秒，9:16 竖屏 |
| 声音 | 旁白、对白、环境音、音乐，或明确无声 | 雨滴声和远处车流环境音，无旁白 |

多镜头时按顺序写：「镜头1：…；镜头2：…」，每个镜头都写清主体、动作和运镜。

结尾写约束声明，例如「无字幕无水印」「人物面部保持一致」「不要出现文字」。

示例：

```text
镜头1：雨后傍晚的老城区石板路，路灯刚亮，一位穿黄色雨衣的小女孩踩进水坑，水花溅起，中景跟拍；
镜头2：镜头缓慢推近到积水倒影特写，倒影里路灯晃动。
电影感写实，暖橙与青蓝对比色调。8 秒，9:16 竖屏。雨滴声和远处车流环境音，无旁白。
无字幕无水印。
```

## 执行

1. 从 agent 上下文的可用 skill 列表里找能生成视频的 skill（描述里写了文生视频、图生视频、视频生成等）。
2. 读它自己的 SKILL.md，按它的文档传入提示词、参考图（如有）、时长、画幅；用它支持的参数表达，不支持的槽位并入提示词。
3. 找到多个时，列出名称和一句话区别，让用户选；不要替用户挑。
4. 一个都没有时，只交付整理好的提示词，并告诉用户可以拿到任意视频生成工具里使用。

本文件不写任何具体 skill 的命令行；怎么调用一律以那个 skill 自己的文档为准。

## 音频

兜底生成的视频需要旁白或配音时，同样按 [audio-omnivoice.md](audio-omnivoice.md) 的决策顺序处理。
