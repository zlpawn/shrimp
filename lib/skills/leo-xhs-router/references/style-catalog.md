# 小红书视觉设计与图卡生成规约

## 一、可插拔生图引擎矩阵（参考 leo-imagine-router 架构）

本 Router 对底层生图/排版引擎完全解耦，支持在 `~/.shrimp/skills/leo-xhs-router/config.json` 中配置或由用户随时切换：

| 引擎类型 | 代表技能 / 工具 | 最佳适用场景 | 核心优势 |
| :--- | :--- | :--- | :--- |
| **HTML 纯代码渲染** | `xhs-html` | 知识干货卡、观点金句、清单合集、大字报 | 62 套纯 HTML 预设，文字 100% 绝对精确，绝不崩字乱码 |
| **AI 扩散生图 / 图生图** | `leo-codex-imagine` / `gpt-image-2` | 氛围封面、产品实物素人化二创、插画背景 | 视觉质感强，擅长将真实项目/工具截图转化为小红书高级图卡 |
| **本地 Python 确定性绘图** | Pillow / SVG 脚本 | 数据对比表、架构图、流程图 | 确定性排版，像素级控制，离线快速出图 |
| **专精艺术画风联动** | `mono-color` / `scenes-gathered` | 文艺单色印刷、复古黑胶、手撕纸实景拼贴 | 极具个人辨识度的杂志级艺术风格 |

## 二、标准卡片尺寸与排版安全区

- **标准比例**：3:4 竖版（默认尺寸 `1080 × 1440` px）；
- **安全边距**：
  - 顶部安全区：保留 120px（避免被小红书客户端顶部关注/返回按钮遮挡）；
  - 底部安全区：保留 160px（避免被点赞/收藏浮层遮挡）；
  - 左右内边距：保留 80px。
- **字号阶梯**（以 1080×1440 为基准）：
  - 封面主标题：60px ~ 80px（粗黑体 / 强视觉抓眼球）；
  - 卡片小标题：40px ~ 48px；
  - 正文解释字：26px ~ 32px；
  - 最小文字限度：不低于 22px（手机端清晰可见）。

## 三、纯读者视角品控禁令（非谈判项）

最终放置在 `图片/发布版/` 的所有图片，**必须完全服务于手机端的普通读者**：

1. **严禁工作流痕迹**：严禁出现“参考原文”、“重绘”、“参考重绘”、“制作说明”、“源文链接”；
2. **严禁 AI 工具标签**：严禁出现“AI 生成”、“AI 绘图”、“提示词”、“prompt”、“AIGC”等降低博主真实感的字样；
3. **严禁占位符**：严禁出现“待提供”、“待替换”、“待确认”、“TODO”、“XXX”；
4. **严禁角标页码**：严禁在卡片角落生硬标注“01/06”、“1/6”、“page 2”等创作者标记；
5. **严禁草稿水印**：严禁残留“DEBUG”、“DRAFT”、“草稿”、“内部测试”。
