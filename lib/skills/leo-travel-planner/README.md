# 🚗 Leo Travel Planner (专业旅行规划师交付级工作台)

`leo-travel-planner` 是一套专为 **独立旅行定制师、行程规划顾问与高端自驾服务机构** 打造的交付级生产力 Skill。它将规划师从查机酒、比距离、算过路费、排动线的繁重苦力中彻底解放，一键生成**兼具金字塔原理、时空交互图表、松弛度假感有人味文案**的单文件独立 HTML 交互路书与精装提案。

---

## 🌟 核心特色与规划师赋能

1. **金字塔原理与度假松弛感（有人味，不严肃）**：
   * 结论先行：首屏 30 秒决策看板（专属卷首寄语、核心风格标签、全包预算总账）；
   * 语言风格温润如老友兼资深管家，充满生活意趣与审美留白，杜绝冰冷机械的“AI 说明书腔”。
2. **行李箱“几何空间”刚性匹配**：
   * 严密规避落地机场行李箱塞不下的尴尬。根据同行人数与 28"/24" 箱型，硬核核验车型后备箱容积（L），自动匹配中大型 SUV 或 7 座 MPV。
3. **物候时令、微气候与动态 B 计划**：
   * 预判彩林黄叶指数与倒影水情，把控日照摄影黄金时刻；
   * 每日前置暴雨/降雪封路的体面替代方案（室内非遗体验、地热温泉下午茶、G30 保底绕行线）。
4. **动力选型与租车全险闭坑**：
   * 高原山地自动规避小排量自吸动力衰减；全险锁定“尊享 0 免赔”（玻璃/轮胎/底盘刮蹭全包）；异地还车费透明单列。
5. **单文件独立可交互 HTML 交付（Zero Dependency）**：
   * 纯原生内嵌 CSS/SVG/JS，断网秒开，微信/邮件一键发送给客户；
   * 内置每日车程游玩甘特图、海拔温差折线图、费用环形图，支持分日折叠与行李清单交互打勾。

* *“三亚到海口 5 天亲子自驾，带长辈和 5 岁孩子，核算行李空间与推荐车型，生成可以直接微信发给客户的交互路书”*
