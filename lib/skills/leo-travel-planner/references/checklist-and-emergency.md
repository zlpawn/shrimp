# 行李清单、应急救援与出游备忘手册 (Checklist & Emergency Guide)

本手册为 `leo-travel-planner` 在生成终版路书时提供自适应的**行李打包 CheckList**、**紧急救援通讯录**与**出行前随检备忘**。

---

## 1. 环境自适应打包 CheckList (根据路线特征动态生成)

### 🪪 基础必带证件与资金
* [ ] 身份证（必须随身携带，严禁放后备箱）
* [ ] 驾驶证原件（自驾必备，租车需核验）
* [ ] 边境通行证（若目的地涉及塔县、白哈巴、阿里、墨脱等边境区域）
* [ ] 少量现金（偏远山区/少数民族集市移动信号差时备用，建议 ¥500~¥1000）

### 💊 医疗与高原防护（若包含高海拔/偏远路线）
* [ ] 布洛芬缓释胶囊（高反头痛/发热）
* [ ] 50% 浓缩葡萄糖口服液（补充体能防脱力）
* [ ] 蒙脱石散 / 肠炎宁（防水土不服腹泻）
* [ ] 晕车贴 / 晕车药（山区盘山公路必备）
* [ ] 创可贴、碘伏棉签、体温计
* [ ] 高原防晒霜（SPF50+）、墨镜、防晒面罩/遮阳帽

### 🧥 穿衣与防寒装备（若昼夜温差 $>15$℃ 或夜温 $\le 5$℃）
* [ ] 排汗速干内衣（严禁全棉内衣）
* [ ] 抓绒衣 / 轻薄排骨羽绒服
* [ ] 三合一防风防水冲锋衣
* [ ] 保暖暖宝宝（贴身及贴手机背面）
* [ ] 保温水杯（清晨看晨雾/日出保命神器）

### 🔌 电子设备与车辆应急
* [ ] 大容量移动电源（20000mAh，注意需可带上飞机）
* [ ] 车载充电器 / 多口快充头
* [ ] 导航手机支架（自驾必备）
* [ ] 离线地图包预先下载（高德地图包）
* [ ] 车载充气泵 / 胎压表 / 拖车绳（无人区/自驾大环线）

---

## 2. 紧急救援与保障通讯录模板 (全路书标配)

在路书末尾统一附带全国及当地救援电话，保障出行安全：

| 机构 / 服务 | 全国统一/救援电话 | 适用场景 |
| :--- | :--- | :--- |
| **全国统一公安报警** | `110` | 紧急安全求助、交通事故、治安事件 |
| **全国统一医疗急救** | `120` | 突发疾病、严重高反、人体创伤急救 |
| **全国公路交通事故** | `122` | 道路交通事故、拖车救援 |
| **全国高速公路救援** | `12122` | 高速公路故障车辆拖车、事故处置 |
| **一嗨租车 24 小时救援** | `400-888-6608` | 自驾抛锚、轮胎破损、事故理赔报案 |
| **气象预警与灾害查询** | `12121` | 当地实时气象与公路封闭查询 |

> 💡 **安全提示**：如在无移动网络信号区域发生紧急状况，手机拨打 `112` 可通过任何可用基站尝试发送紧急求救信号。
