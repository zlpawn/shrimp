# 行李清单、应急救援与专业装备备忘手册 (Checklist & Emergency Guide)

> 💡 **规划师内参**：清单不是千篇一律的模板堆砌，而是结合路线环境（海拔、极温、路况、同行人画像）精确输出的**专业行前安全底座**。

---

## 1. 动态打包 CheckList（根据环境特征自适应激活）

### 🪪 基础必带证件与资金（随身随检）
* [ ] 身份证原件（沿途检查站密集，随身携带，严禁收进行李箱深处）
* [ ] 驾驶证原件（正副页齐全，用于落地车行核验与沿途交警临检）
* [ ] 边境通行证（若涉及塔县、白哈巴、阿里、墨脱、定日珠峰等边境区域）
* [ ] 应急现金（¥800 ~ ¥1500，偏远山区或牧区集市移动信号弱时备用）

### 🏔️ 高原与高海拔专业保障（海拔 $\ge 2500$m 必配）
* [ ] **指夹式脉搏血氧仪**（几十元随身备一个，数据说话，监测血氧防隐性肺水肿）
* [ ] **落地租用便携车载双模制氧机**（车充+电池+室内220V三用，日租约¥50~80，淘汰一次性铁罐）
* [ ] **布洛芬缓释胶囊（芬必得）**（神经性头痛对症有效止痛）
* [ ] **50% 浓缩高渗葡萄糖口服液**（眩晕虚脱时秒补脑能量）
* [ ] **角鲨烯胶囊 / 红景天苷**（出行前 3~5 天提前服用提高耐缺氧储备）

### ❄️ 高寒、冰雪与暗冰行车保障（夜温 $\le 5$℃ 或翻越雪山山口）
* [ ] **-25℃~-40℃ 极寒专用防冻玻璃水**（落地取车强制排查，严禁使用 0℃ 普通水导致管路冻裂）
* [ ] **破冰型防滑链**（随车备一副与轮胎尺寸完全吻合的防滑链，挂在驱动轮上）
* [ ] **长柄除雪防霜铲**（清理前挡晨霜；露天过夜雨刮器立起）
* [ ] **“洋葱式”防风保暖衣物**（排汗速干内衣 + 抓绒中层 + 三合一防水透汽冲锋衣 + 便携薄羽绒）
* [ ] **长效暖宝宝贴片**（贴身保暖 + 贴于手机/相机背面防止锂电池低温休眠跳电）
* [ ] **真空保温水杯**（严寒清晨看晨雾/雪山日照金山保命必备）

### 🏜️ 荒野戈壁与长途通信保障（无人区/长途公路）
* [ ] **支持北斗卫星短信的手机 / 租用天通卫星电话**（无基站信号盲区报平安与紧急求救）
* [ ] **高德地图离线全国及全省数据包**（出发前在 WiFi 环境下载完毕，离线断网依然精准导航）
* [ ] **车载双缸金属充气泵 + 胎压表**（沙地放气脱困后，必须重新充气至 2.3 bar）
* [ ] **车用多口大功率快充头 + 20000mAh 可登机移动电源**
* [ ] **后备箱应急维生储备**（至少储备 2 箱瓶装饮用水 + 压缩饼干/牛肉干/巧克力）

### 👴 长辈与儿童专项关怀装备
* [ ] **航空铝合金超轻便携折叠轮椅**（自重仅 6.8kg，折叠后如小箱，平坦步道推着长辈走，体面省力）
* [ ] **晕车药（茶苯海明）**（出发车轮启动前半小时温水服用）+ 晕车贴（贴耳后无发处）
* [ ] **长辈专属便携药盒**（按早中晚分装高血压、糖尿病等日常慢病用药）
* [ ] **高倍防晒霜 SPF50+、大帽檐遮阳帽、UV400 偏光墨镜**（保护长辈白内障眼角膜免受高原强紫外线灼伤）

## 2. 🚨 24h 紧急救援与保障通讯录模板 (路书全标配)
