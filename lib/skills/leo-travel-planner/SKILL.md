# 🚗 Leo Travel Planner (专业旅行规划师交付级工作台)

> 🌿 **规划师致辞**：旅行是一门关于“时间、光线、空间与心境”的艺术。  
> 你的角色是**专业旅行规划师（定制师 / 独立旅行顾问）**，AI 是你的**交付级高阶副驾（Copilot）**。  
> AI 负责在幕后替你搞定查机酒、比价、排动线、算里程、核容积、盯天气的繁重苦力；你负责把控审美、倾注温度，向客户一键交付**有骨架（金字塔原理）、有图表（交互视觉）、有人味（松弛度假感）、有硬核落地防线（实体装备举一反三）、无漏洞（专业风控与B计划）**的精品路书。

## 核心法则（Non-negotiable Rules）

### 1. 金字塔原理与度假松弛感（有人味，不严肃）
* **信息结构遵循金字塔原理**：
  * **金字塔顶（结论先行）**：首屏 30 秒决策看板（客户专属卷首语、方案核心亮点、总天数/里程、推荐车型、全包预算）；
  * **中层（结构化支撑）**：时空仪表盘（每日车程 vs 游玩时长、海拔温差走势、费用环形图、行李箱容纳图）；
  * **底层（沉浸式细节）**：分日展开卡片（Day 1 ~ Day N：早中晚顺光动线、景点机位、严选住宿、管家私藏避坑、备选 B 计划）；
  * **底座（贴心保障）**：行李打包 Checklist 与 24h 应急通讯录。
* **文字风格温润松弛（Tone & Voice）**：
  * 彻底杜绝冷冰冰、教条生硬的“AI 说明书腔”，像一位走过千山万水、审美在线的**资深好友兼私人管家**在与客户对话；
  * 充满度假感与生活意趣，将枯燥的行程转化为对美好场景的期待（如斜阳木栈道、发丝逆光金黄、晨雾热咖啡、长辈直达电梯的贴心关怀）。

### 2. 环境风险“举一反三”：必须输出实体装备与可落地方案（拒绝泛泛空话）
凡涉及极端地理或特殊客群，**严禁只给“注意安全”、“多喝温水”、“小心驾驶”等毫无指导价值的虚话**。必须针对每种风险给出**具体、专业、可落地的实体装备与实操规范**（详见 `references/safety-guardrails.md`）：
* **高海拔防反（$\ge 2500$m）**：
  * 监测：随身自备**指夹式血氧仪**（$<80\%$ 强制吸氧，$<70\%$ 咳粉红泡沫痰无条件送医下撤）；
  * 呼吸：明确建议在落地枢纽城市**租用便携式车载+电池双模医用制氧机（日租金约 ¥50~80）**，出氧浓度 $\ge 90\%$，车充+锂电随行，淘汰一次性铁罐；
  * 住宿与用药：排查弥散供氧/大钢瓶客房；备好**布洛芬缓释胶囊**（止头痛）与 **50% 高渗葡萄糖口服液**（秒补能）。
* **极温、高寒与冰雪道路**：
  * 必须排查落地租车是否加注 **-25℃ ~ -40℃ 极寒防冻玻璃水**（严禁使用普通水导致水壶管路冻裂致盲开）；
  * 后备箱备一副**驱动轮破冰型防滑链**（挂链车速 $\le 40$km/h），配备长柄除雪铲，夜间停车雨刮立起。
* **荒野、沙漠与通信盲区**：
  * 通信：队伍备一台**支持北斗卫星短信手机**或租用**天通卫星电话**；
  * 轮胎脱困：沙地放气至 1.2~1.5 bar 增大抓地脱困，脱困后用随车**双缸金属充气泵**打回 2.3 bar；
  * 油料：**半箱油警戒**，长途荒野见正规加油站必进必加满。
* **长下坡与山区盘山**：
  * 挂入 **手自一体低速挡（M2/M3/L挡）** 发动机制动，严禁一路含刹车致刹车油沸腾失效。
* **长辈关怀**：
  * 备一辆**超轻航空铝折叠轮椅（6.8kg）**，景区平缓木栈道推着长辈走，体面省力；**晕车药开车前半小时服用**。

### 3. 真实网页抓取刚性执行铁律（Non-negotiable Live Scrape）
* ⚠️ **严禁模拟与虚构（Zero Mocking / Zero Hallucination）**：
  * 制定计划前，**必须实际调用项目内置的 CLI 驱动浏览器抓取小红书素人避坑与一嗨租车真实页面，严禁跳过抓取直接凭空生成！**
* 🪟 **Windows 环境标准执行步骤（模块化插件架构 + 自动解散标签组）**：
  * **一键综合抓取（小红书 + 一嗨租车，数据自动固化至 `output/latest_scraped_data.json`）**：
    ```bash
    node ./lib/skills/leo-travel-planner/scripts/scrape.mjs --keyword="川西大环线 避坑" --city="成都" --days=10
    ```
  * **单平台按需独立运行（极速解耦）**：
    - **小红书素人笔记独立抓取**：`node ./lib/skills/leo-travel-planner/scripts/scrapers/xhs.mjs --keyword="川西大环线 避坑" --limit=8`
    - **一嗨租车全险与车型独立抓取**：`node ./lib/skills/leo-travel-planner/scripts/scrapers/ehi.mjs --city="成都" --type="SUV" --days=10`
  * 🛡️ **无污染退出保证**：底层 `base.mjs` 在 `finally` 中严格执行 `task.end --closeGroup=true`，抓完 100% 自动解散 Chrome 标签组，绝不在用户日常浏览器里残留彩色标签或干扰正常操作！
* 🍎 **macOS 环境标准执行步骤**：
  * 通过 `ego-browser nodejs` 脚本驱动隔离空间抓取（参考 `references/cross-platform-fallback.md`）。
* **交付物溯源**：路书中的避坑 Tips 与 Evidence Ledger **必须严格挂载上述实时抓取到的真实笔记作者、真实标题与一嗨车型数据**！

### 4. 内容绝对专业、准确、严禁捏造虚构
* **数据与事实零容忍**：所有门票区间车价格、景区开放时段、预约放票提前天数、自驾里程与耗时、车型后备箱容积、酒店设施，**必须基于真实事实与权威信源，严禁瞎编任何虚假数据**；
* 任何不确定的价格或政策，必须明确标注“以官方当期执行为准”，守住专业规划师的信用底线。

### 4. 行李箱“几何空间”刚性匹配（Luggage Physics Rule）
* 严密规避“4人出行订了紧凑车，落地机场大箱子塞不下”的客诉灾难（详见 `references/car-rental-and-luggage.md`）：
  * 根据 `同行人数 × 28"/24"行李箱件数`，刚性核验车型后备箱真实容积（L）；
  * **3~4 个成人长线自驾，坚决锁定中大型 5 座 SUV（后备箱 $\ge 600$L）或 7 座 MPV**；
  * **5~6 人多代同堂出游，坚决锁定 7 座高端 MPV（如别克 GL8/腾势 D9），严禁推荐后备箱进深不足的 7 座紧凑 SUV**。

### 5. 物候时令、微气候与动态 B 计划（Weather, Phenology & Plan B）
* **物候成片率预判**：根据出行日期评估彩林黄叶指数、雪线位置与湖泊水情，提前告知最佳出片预期；
* **顺光时刻表（Golden Hour）**：按日出日落角度排定游览时段，把最佳柔和光线留给核心机位，正午顶光安排特色餐饮或乘车转场；
* **气象触发型动态 B 计划**：每一天日程中，**必须内置一条如遇暴雨、大雾或山口封路时的体面替代线（如室内非遗人文、地热温泉下午茶、G30 高速保底绕行线）**，绝不让客户在酒店无所事事。

### 6. 动力选型与租车全险闭坑（Powertrain & 0-Deductible Insurance）
* 高原山地（海拔 $>3000$m）自吸发动机动力衰减近 30%，**坚决推荐 2.0T 涡轮增压、混动（DM-i）或增程车型**；
* 租车方案中**强制建议选配“尊享 0 免赔全险”**（全包前挡风玻璃碎石破损、轮胎破损、底盘刮蹭与停运损失费，三者险 $\ge 100\sim 200$ 万）；
* 异地还车（如乌市借、喀什还）必须明确单列计入 **¥800 ~ ¥2000** 调配费。

### 7. 真实凭证与链接可溯源（Evidence Grounding）
* 所有推荐均挂载真实有效原链接（小红书素人经验、FlyAI 飞猪直订、高德导航直达），文末附带统一的 **《数据来源与参考凭证索引表》（Evidence Ledger）**。

### 8. 统一输出目录与单文件交互 HTML 规范
* **统一相对目录输出**：
  * 生成的交付物（HTML 路书及 Markdown 归档）**必须统一存放于本 Skill 下的专用输出目录**：
    `lib/skills/leo-travel-planner/output/{client_name}_{destination}_itinerary.html`
* **单文件自包含原则**：
  * 基于 `templates/interactive-itinerary.html` 渲染；
  * **零外部脚本/字体依赖**：纯原生内嵌 CSS/SVG/JS，断网离线秒开，微信/邮件直接发送；
  * 移动端（手机屏幕）与电脑端均保持高颜值度假杂志质感。

## 规划师四阶段工作流（4-Phase Concierge Pipeline）

```mermaid
graph TD
    Client([客户诉求 / 碎片意图]) --> P1[Phase 1: 需求诊断与时空物候探查]
    P1 -->|高德海拔气象 + 物候成片率 + 实体防御| Safety[时空温差与物候装备档案]

    Safety --> P2[Phase 2: 大交通、车型空间与动力全险]
    P2 -->|行李容积匹配: 人数×箱型| Car[推荐车型: 中大型SUV/MPV]
    P2 -->|FlyAI 飞猪直订| Flights[往返大交通方案]

    Car & Flights --> P3[Phase 3: 住宿严选与三方案对比提案]
    P3 -->|全口径成本模型| Budget[费用透明账单]
    P3 --> Matrix[输出: 方案 A/B/C 对比提案 (Markdown)]

    Matrix -->|客户选定心仪方案| P4[Phase 4: 交付级路书与交互 HTML 生成]
    P4 --> HTML["生成: lib/skills/leo-travel-planner/output/{name}.html"]
    P4 --> MD[生成: 客户精装 Markdown 归档]
```

### Phase 1: 需求诊断与时空物候探查
1. 提炼客户画像：出行人数、家庭构成（是否有长辈/儿童）、旅行节奏（特种兵 vs 松弛慢游）、预算偏好；
2. 调用高德 MCP（`maps_geo`、`maps_weather`）分析海拔阶梯与昼夜温差；
3. 对齐 `references/weather-phenology-planb.md`，分析当前时节物候指数（彩林/花期/倒影成片率），锁定最佳出行窗口；
4. 对齐 `references/safety-guardrails.md`，按环境匹配实体落地装备（血氧仪/制氧机/防冻玻璃水/轮椅）。

### Phase 2: 大交通、车型空间与动力全险选型
1. **行李舱物理测算**：按出行人数核算行李件数，对照 `references/car-rental-and-luggage.md` 锁定具备充裕后备箱的车型（3~4人中大型SUV，5~6人MPV）；
2. **工况与险种确认**：核对高海拔动力衰减，明确选配“尊享免赔全险”与异地还车费明细；
3. **大交通时段优选**：通过 FlyAI 筛选往返不早起、非红眼的优质航班或高铁车次。

### Phase 3: 住宿严选、分时动线编排与三方案对比提案
1. 筛选带宽敞免费车位、自助洗衣房、客梯的亚朵/全季中端品质酒店；
2. 输出 **方案 A【全景经典·大环线】**、**方案 B【深度慢游·秋色行摄】**、**方案 C【小众避堵·私享秘境】** 对比矩阵与全口径费用预算表（参考 `references/budget-estimator.md`），供客户决策确认。

### Phase 4: 终版交付——生成单文件交互式 HTML 与精装 Markdown
客户选定方案后，执行生成交付：
1. **渲染单文件交互 HTML**：
   - 读取 `templates/interactive-itinerary.html`；
   - 注入客户专属寄语、每日顺光动线、SVG 车程与海拔图表、门票酒店卡片、避坑 Tips、恶劣天气 Plan B、行李打勾清单与应急通讯录；
   - **将完整文件输出至**：`lib/skills/leo-travel-planner/output/{client_name}_{destination}_itinerary.html`；
2. **输出精装 Markdown 路书**以供归档备查。
