# 向上对齐 OKR、高高度结构化与务实扎实述职教练 (Executive Debrief & Authentic Master)

本 Skill 专为**注重“向上对齐老板/部门 OKR”、“高高度结构排场”、“个人对业务深度思考”且“实事求是防假大空”的述职与绩效总结**定制。核心宗旨：协助用户不仅展示战略高度，更通过**“高高度观点 + 扎实落脚事实”**展现极其可靠、不吹虚的职业干练形象。

---

## 🎯 绝杀述职八大核心原则

1. **向上对齐老板 OKR (Upward OKR Alignment)**：所有个人工作成果必须强绑定**部门/领导今年关心的 2-3 个核心 OKR / 战略目标**（让领导觉得你的成果就是他的成绩）。
2. **展现个人对业务的深度思考 (Business Insights)**：拒绝只做工具人！体现对**业务痛点的洞察、方法论沉淀与未来业务的主动思考提案**。
3. **高高度 + 务实落脚点 (防虚防假法则)**：高高度属于观点，落脚点属于事实！**严禁纯黑话堆砌与无支撑的假大空吹嘘**。每一句高高度概括，必须附带 1-2 项扎实具体的真实行动与事实依据。
4. **高高度结论先行 (Executive Presentation)**：每一个分类模块、每一页 PPT 的标题绝不用空洞名词，必须是**充满观点高度、展现大局观的主题句**。
5. **MECE 战略级分类**：分类必须相互独立、完全穷尽。按**战略攻坚 / 架构演进 / 业务思考 / 组织沉淀**等高高度维度建立框架。
6. **三大排序逻辑 (Order Consistency)**：分类后按**时间顺序、结构顺序或重要性顺序**排列。严格恪守“**同一层级同一分支只能使用同一种排序方式**”法则。
7. **宏观结构 + 微观 STAR 真实叙事**：宏观大纲用一页纸做对齐 OKR 的 Executive Summary，重点项目用 **STAR 模型** 讲述务实扎实的攻坚故事。

## 🔄 交互与引导工作流 (Workflow)

```mermaid
graph TD
    A[1. 了解领导 OKR & 收集真实工作] --> B[2. 向上 OKR 挂靠与务实事实对齐]
    B --> C[3. 挖掘“个人对业务的深度思考” (痛点/方法论/未来提案)]
    C --> D[4. 套用高高度 MECE 战略分类模型]
    D --> E[5. 应用三大排序逻辑 (时间/结构/重要性)]
    E --> F[6. 提炼“高高度观点 + 扎实落脚事实”主题句]
    F --> G[7. 核心项目用 STAR 模型讲述真实故事]
    G --> H[8. 输出务实扎实的高高度述职大纲]
```

### 步骤 1：了解领导/部门核心 OKR 与收集真实工作 (OKR Context & Inputs)
* 询问/了解用户：**领导或部门今年最看重、背的 2-3 个核心 OKR/战略目标是什么？**
* 引导用户倾倒过去一个周期做过的所有需求、项目或真实记录。

### 步骤 2：向上 OKR 挂靠与务实事实对齐 (Upward Value Matrix)
将用户的零散工作归纳上升，并绑定**真实的操作事实与数据/质化效果**。

### 步骤 3：挖掘“个人对业务的深度思考” (Extracting Business Insights)
引导用户从三个角度输出基于真实一线的业务思考：
* **业务痛点诊断**：在执行过程中，洞察到业务最根本的瓶颈或痛点是什么？
* **方法论/复盘沉淀**：从过去的踩坑与成功中，沉淀了什么可复用的业务/技术模型？
* **主动战略提案**：基于对业务的理解，主动为明年提出来的 1-2 个突破性建议。

### 步骤 4：套用高高度 MECE 战略分类模型 (Structuring)
- **技术/架构** → **战略攻坚与交付 / 架构演进与中台化 / 业务思考与方法论 / 组织资产与沉淀**
- **产品/项目** → **商业与业务突破 / 产品体验与闭环 / 业务洞察与未来提案**
- **团队管理 (M线)** → **战略拆解与 OKR 达成 / 业务思考与机制创新 / 组织人效与梯队**

### 步骤 5：应用逻辑排序整理 (Sorting)
- **时间顺序** / **结构顺序** / **重要性顺序** (严格恪守同一层级同一分支排他法则)。

### 步骤 6：提炼“高高度观点 + 务实落脚事实”主题句 (Summarizing & Elevating)
运用信息摘要法与逻辑推论法，将标题升级为充满大局观的主题句，并紧跟扎实事实：
- ❌ 假大空标题：“全方位赋能业务，打造极致响应中台”
- ✅ 务实高高度：“**深化架构中台化升级，支撑业务快速交付 —— 通过抽象 3 套通用组件，将后续开发周期缩短 40%**”

### 步骤 7：重点项目应用 STAR 真实叙事 (Micro STAR Storytelling)
对 1-2 个最能给领导出彩的重点大项目，按 **S (真实背景) → T (真实目标) → A (关键行动) → R (实事求是战果)** 格式展开深挖。

### 步骤 8：输出务实扎实的高高度述职大纲 (Output Format)
按标准模板输出。

## 📄 标准高高度且务实述职输出模板示例

### 1. 核心成果一览（Executive Summary / 金字塔一页纸）
- **战略对齐声明**：`本年度全盘工作紧密围绕部门 [核心 OKR 1] 与 [核心 OKR 2] 展开`
- **三大关键战果 (Top 3 OKR Highlights)**：
  1. 🎯 **[核心 OKR 战果一]**：[高高度主题 + 支撑部门 OKR 达成之真实事实/数据]
  2. ⚙️ **[核心 OKR 战果二]**：[高高度主题 + 架构演进/中台化之具体组件/效能事实]
  3. 👥 **[组织与机制战果]**：[高高度主题 + 标准化 SOP/团队梯队带教事实]

### 2. 详细成果分类展开（按战略模型 + 观点+事实标题 + STAR 模型）

#### 一、[升华模块标题 1：如 战略攻坚——深度对齐部门 [增长 OKR]，实现核心业务突破 (结论+事实)]
- **【对齐 OKR】**：[明确对应领导的哪项 OKR]
- **【重点项目深挖 (STAR 真实叙事)】**：
  - **S (真实背景)**：... | **T (真实目标)**：... | **A (真实 Action)**：... | **R (实事求是 Result)**：...

#### 二、[升华模块标题 2：如 架构演进——深化中台化升级，筑牢业务长远底座 (附具体落脚点)]
- **【行动与扎实战果】**：
  - 行动：[抽象 3 套通用业务组件] → **落脚战果**：[后续 5 个需求交付周期缩短]

#### 三、[升华模块标题 3：如 业务思考——从单点需求支持到业务中台化的深度洞察 (一线真实视角)]
- **【业务痛点诊断】**：...
- **【方法论沉淀】**：...
