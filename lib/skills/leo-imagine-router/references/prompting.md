# 通用提示词组织规范 (Prompting Guidelines)

为保证生图模型（包括 DALL-E-3、Flux、gpt-image-2 等）输出稳定、画面干净且高度贴合需求，Agent 在构造 `--prompt` 时应遵循本规范。

---

## 核心原则 (Core Rules)

1. **防过度加料 (Anti-Overprompting)**：
   - 已经足够具体的 Prompt，**不要过度发散或随意加料**，只做清晰的结构化整理。
   - 严禁盲目堆砌无意义套话（如 "masterpiece", "8k resolution", "trending on artstation" 等）。
2. **文字防乱码 (Text in Quotes)**：
   - 当画面需要渲染中文或英文特定字样时，**务必将文字原文置于双引号内**（例如：`中央标语显示："未来城市"`）。
3. **图像编辑明确变更范围 (Edit Isolation)**：
   - 进行参考图局部修改或图生图时，必须明确写出：**只改什么、保留什么不变**（例如：`只替换背景为纯白；保留主体人物表情、姿态与光影不变`）。
4. **简洁 6 槽位结构**：
   - 通用任务建议按以下槽位组织提示词：
     - **用途**：应用场景（如：信息图 / 封面图 / 架构图 / 头像 / 插画）
     - **主体**：核心主体、人物、物体或视觉焦点
     - **场景**：环境、光影、背景氛围
     - **风格**：艺术表现形式（如：扁平矢量、3D渲染、摄影实拍、二次元、国风水墨）
     - **构图**：比例、视角、主体布局与留白
     - **约束**：负向排除与必要限制（如：无水印、无无关文字、不要杂乱元素）
