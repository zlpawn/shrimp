# Safety

- Do not reverse or call Jianying account APIs.
- Do not read cookies, tokens, or login state.
- Do not click the Jianying UI to edit.
- Refuse homepage registration while Jianying is running.
- Never overwrite an existing draft directory.
- Always mint a new project ID.
- Backup root_meta_info.json before registration and restore it on failure.
- Keep media inside the draft; do not upload user assets unless the user explicitly asks.
- Personal templates are created only on an explicit save intent.
