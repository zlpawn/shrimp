# 携程问道旅行查询

触发时机：用户提出旅行相关问题，或明确提到携程问道、机票、酒店、行程、景点、美食、签证、交通。

唯一用法：

```bash
leo-wendao "用户的完整问题原文"
```

规则：

- query 必须使用用户原话全文，不要摘要、改写或拆分。
- 成功时直接把 stdout 的 Markdown 原文呈现给用户。
- stdout 为空或 exit 1 时告知用户稍后再试，不要编造内容。
- 同一问题 60 秒内不要重复调用；CLI 已内置 4s/8s 两次短结果重试。
- 如果提示 token 未配置，告诉用户运行 `leo-wendao login`；不要让用户把 token 发到聊天里。
- 永远不要查看、读取、输出或复制 token 文件；token 也不会出现在命令行参数中。
