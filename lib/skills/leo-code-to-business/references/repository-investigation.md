# Repository Investigation

## Purpose

Make model-led code investigation deep, repeatable, and auditable.

## Mandatory Investigation Kinds

Record vocabulary expansion, entry search, forward trace, backward trace, alternate-entry search,
rule search, contradiction search, and current source verification.

Each record names exact queries, scope, inspected files/symbols, candidates, accepted and rejected
results, truncation, provider, repository snapshot, and verification state.

## Gate

A truncated search is incomplete until narrowed or explicitly marked partial. A remembered or
tool-returned relationship is not confirmed until its current source is reopened.
