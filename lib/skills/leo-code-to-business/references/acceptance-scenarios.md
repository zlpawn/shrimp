## Work-Order Creation

Explain how a work order is created from actor/goal through business rules, external creation,
success/failure, and searched unknowns. Do not invent authorization, duplicate prevention, image
constraints, or time validation.

Explain tenant selection, duplicate rejection, device branch, folder expansion, binding data,
index synchronization, failure behavior, and the full family: normal, 3D, uploaded, pending-upload,
WXON, precheck/status, unbind, and operational relink.
