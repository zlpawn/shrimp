# 跨模型决策表

不同模型必须使用本表做关键分类，不用个人偏好替代条件。

## 1. Skill 类型

| 条件 | 结论 |
|---|---|
| 至少两个动作有明确先后证据 | `execution` |
| 只有框架、原则或判断维度，没有可靠顺序 | `guidance` |
| 顺序由模型推断而非课程明确表达 | 不生成执行序列；使用 `guidance` |
| 口述和课件对步骤顺序存在开放冲突 | 暂停生成，呈报冲突 |

## 2. 场景边界

| 条件 | 处理 |
|---|---|
| 用户场景与课程明确场景一致 | 继续 |
| 两个场景共用框架，但输入、输出或验收对象不同 | 拆成两个 Skill |
| 只是同一场景的角色或行业差异 | 保留一个 Skill，在模型自由区适配 |
| 用户场景只有课程标题支持，正文无证据 | 报告证据不足 |

## 3. 课程事实与派生规则

| 内容来源 | 分类 |
|---|---|
| 讲者明确给出的步骤、原则或检查点 | `[COURSE_EVIDENCE]` |
| 多段课程证据的同义归纳，无外部信息 | `[COURSE_EVIDENCE]`，`evidence_type: synthesized` |
| 为保证执行完整性增加的格式、追问或机器门禁 | `[DERIVED_TEMPLATE]` |
| 根据用户材料写出的具体内容 | `[MODEL_OUTPUT]` |
| 常识上合理但课程未讲 | 不进入课程事实；必要时作为派生规则并明确标记 |

## 4. 视觉证据

| 可用能力 | `visual_status` | 使用方式 |
|---|---|---|
| 多模态 + OCR | `multimodal_and_ocr` | 多模态理解关系，OCR 提供文字索引 |
| 仅多模态 | `multimodal_only` | 保存描述、可见文字和关系 |
| 仅 OCR | `ocr_only` | 只采信可识别文字，不推断箭头、版式或强调 |
| 两者均不可用 | `not_audited` | 依赖 ASR，明确视觉未审计 |

多模态和 OCR 冲突时，保留两个结果并写入 `uncertain_items`。不得让 OCR 自动覆盖视觉关系，也不得让多模态模型凭模糊画面改写清晰 OCR 文字。

## 5. 不确定与冲突

| 情况 | 处理 |
|---|---|
| ASR 听不清、OCR 模糊或画面遮挡 | `uncertain_items` |
| 讲者口述与课件版本不同 | 两个版本均保留，`conflict_status: open` |
| 用户明确选择其中一个版本 | `resolved_by_user`，记录选择 |
| 模型只能靠上下文猜测 | 不填事实字段 |

## 6. 缺失检查点

课程未给检查点时，不在 `methodology.json` 中补写。可以在 `skill-spec.json` 的步骤中增加执行门禁，但必须标为 `[DERIVED_TEMPLATE]`，并且不能改变课程步骤含义。
