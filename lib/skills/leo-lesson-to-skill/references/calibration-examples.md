# 行为校准样例

这些样例用于统一不同模型对“忠实提炼”和“合理派生”的边界。

## 1. 合理归纳

课程证据：

- `ASR-S0010`：“先把目标说清楚。”
- `FRAME-0003`：“第一步：明确目标。”

正确：

```text
[COURSE_EVIDENCE] 第一步是明确目标。
source_refs: [ASR-S0010, FRAME-0003]
evidence_type: synthesized
```

原因：两条证据表达相同含义，没有加入新规则。

错误：

```text
[COURSE_EVIDENCE] 第一步要用 SMART 原则明确目标。
```

原因：课程证据没有出现 SMART。

## 2. 课程检查点与派生门禁

课程说：“成果没有数据就打回去补。”

正确：

```text
[COURSE_EVIDENCE] 成果必须有数据；没有数据则补充。
```

课程只说：“列出成果。”

允许：

```text
[DERIVED_TEMPLATE] 如果用户没有提供成果信息，先追问，不虚构。
```

不允许：

```text
[COURSE_EVIDENCE] 每个成果必须有数据。
```

原因：这是模型补出的课程规则。

## 3. 场景拆分

课程分别讲“向上汇报”和“年终述职”，两者听众、结构和验收标准不同。

正确：生成两个 Skill。

课程只讲“年终述职”，例子分别来自销售和研发。

正确：生成一个述职 Skill，把行业差异放在 `[MODEL_OUTPUT]` 自由区。

## 4. 视觉证据

画面显示“目标 → 行动 → 结果”，OCR 得到“目标 行动 结果”。

正确：多模态通道记录箭头关系，OCR 通道记录文字。

错误：只有 OCR 时断言课程规定了从左到右的严格流程。

原因：OCR 不提供箭头或版式关系。

## 5. 不确定内容

ASR：“第三步是……复盘/复核”，无法确认。

正确：进入 `uncertain_items`，保留时间戳和两个可能词。

错误：选择“复盘”并写入正式步骤。

## 6. 模型自由区

Skill Spec 锁定“目标、成果、反思、计划”四部分。

允许不同模型：

- 使用不同标题措辞；
- 对用户材料进行不同但合理的归类；
- 调整语气和详略；
- 针对行业替换表达。

不允许：

- 删除“反思”；
- 把“计划”移到“成果”之前；
- 添加课程未规定的第五个核心阶段；
- 忽略明确反模式。
