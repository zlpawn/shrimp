# Dream Skin third-party assets

The renderer and stylesheet files under `engines/` are copied unchanged from
the upstream assets bundled by BigPizzaV3/CodexPlusPlus:

- `dream-skin/`
- `cidala-tiger/`
- `glass-vision/`
- `snow/` (named `snow-skin` upstream)

Each engine directory contains the applicable upstream MIT license, including
the original copyright and attribution notices. Shrimp's Node.js launcher,
CDP client, path handling, placeholder substitution, and cleanup integration
are implemented separately in this repository.
